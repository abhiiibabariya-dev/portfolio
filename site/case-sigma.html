PROJECT CASE STUDY

Sigma Rule
Converter.

A detection engineering utility designed to help translate Sigma detection logic into SIEM-specific query languages.

Problem

Detection teams often need to express similar logic across different SIEM platforms. The project is designed around writing detection logic once and converting it for multiple backends.

Supported Platforms

Splunk SPL, Microsoft KQL, Elastic EQL/Lucene, QRadar AQL and Chronicle YARA-L are documented in the repository.
